# 🕯️ Candle Quest Reborn

**Candle Quest** is a mobile-friendly trading education game that helps beginners build visual intuition for candlestick movement, support and resistance, breakouts, fakeouts, trend behaviour, and basic risk awareness.

Instead of learning through long textbook explanations, players learn by watching a simulated market move, reacting to frozen chart moments, and choosing the correct market read.
